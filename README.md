# WedVision

A visual introduction to custom technology for wedding businesses.

## Run locally

Run `python server.py` or double-click `start-local.bat`, then open http://localhost:3000. No package installation is required.

## Active files

- `public/index.html`: homepage and inline vector symbols.
- `public/story.css`: warm white, near-black and logo-magenta design; responsive visual scenes and animation.
- `public/story.js`: scroll reveals and navigation state, with reduced-motion support in CSS.
- `public/fonts.css`: existing local font faces.
- `public/wedvision-logo.png`: supplied square mark.
- `public/wedvision-landscape.png`: supplied white wordmark for the dark contact panel.
- `public/privacy-policy/index.html` and `public/terms/index.html`: branded shells; approved legal text is still required.

Replace #contact on meeting buttons with the actual booking destination. Social links also remain placeholders, marked with TODO comments. All interface previews are illustrative examples of custom work, not ready-made products or customer results.
